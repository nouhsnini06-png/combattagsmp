# CombatTagSMP
A lightweight Paper/Spigot 1.20+ plugin designed for SMP servers to prevent combat logging.

### Features
- **Combat Tagging:** Tags both attacker and victim for 15 seconds upon PvP damage.
- **Anti-Combat Log:** Instantly eliminates players who disconnect during active combat.
- **Command Blocker:** Prevents players from using teleport or escape commands while tagged.
- **ActionBar Timer:** Displays a live countdown above the player's hotbar.
